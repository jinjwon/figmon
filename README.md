# Figmon 🥚✨

**작업한 시간만큼 같이 자라는 포켓몬 데스크톱 펫** (macOS)

Figma로 디자인하거나 VS Code·Xcode·터미널에서 코딩하면 포켓몬이 자라요.
펫은 화면 아래를 돌아다니다가, 일할 때는 커서 옆에 와서 지켜보고, 유튜브·인스타·게임을 켜면 달려와서 말려요.

## 이런 걸 해요

- 🐣 **1~9세대 스타팅 27마리** 중 하나를 골라 알부터 키워요. Lv.3에 부화하고, Lv.16에 1차 진화, Lv.36에 최종 진화해요.
- 🚶 **데스크톱 펫**: 투명한 창 속 포켓몬이 화면 아래를 걸어 다녀요.
  - 작업 중: 커서 근처로 와서 앉아 지켜봐요 👀
  - 딴짓 중: 커서로 달려와서 부들부들 떨어요
  - 자리비움: 잠들어요
  - 끌어서 던질 수 있고(떨어져서 착지해요), 클릭하면 대시보드가 열려요
  - 레벨이 오를수록 몸집도 조금씩 커져요
- 🎨💻 **디자이너·개발자 겸용**: Figma, Sketch, Framer, VS Code, Cursor, Xcode, JetBrains, 터미널(iTerm2, Warp…), github.com 등이 작업으로 잡혀요. 설정에서 프리셋을 바꾸거나 직접 고칠 수 있어요.
- 🍿 **휴식 잔고**: 작업 5분마다 휴식 1분이 쌓여요. 잔고가 남아 있으면 유튜브를 봐도 페널티가 없어요.
- 💢 **페널티**: 잔고가 0인데 딴짓하면 macOS 알림과 "작업으로 돌아갈게" 팝업이 떠요. 20초 안에 돌아가지 않으면 분당 경험치 -3. 레벨은 떨어져도 퇴화는 안 해요.
- 🧠 **AI 절제 모드**(선택): ChatGPT·Claude·Gemini 등을 하루 무료 시간(기본 30분)까지만 써요. 넘기면 딴짓으로 쳐요.
- 🏆 **자랑 카드**: 최종 진화하면 공유용 이미지 카드가 자동으로 떠요(저장 / 공유 / X / 문구 복사). 졸업시키면 도감에 등록되고 새 파트너를 키울 수 있어요.

## 설치 & 실행

필요한 것: macOS, Python 3(기본 내장), Xcode Command Line Tools(데스크톱 펫 빌드용).

```bash
xcode-select --install   # 처음 한 번만, 이미 있으면 생략
git clone https://github.com/jinjwon/figmon.git
cd figmon
./start.command
```

Finder에서 `start.command`를 더블클릭해도 돼요. 처음 실행할 때 데스크톱 펫을 자동으로 빌드해요.

- 메뉴 막대의 `🎨 Lv.12` 아이콘이나 펫 우클릭 메뉴에서 대시보드 열기 / 부르기 / 숨기기 / 종료를 할 수 있어요.
- 처음 실행하면 macOS가 "Chrome(또는 Safari)을 제어하려고 합니다"라고 물어요. **허용**해야 지금 보는 사이트(유튜브인지 github인지)를 구분할 수 있어요.
- 데이터는 `~/.figmon/state.json`에 저장돼요.

### 빨리 감기 테스트

```bash
FIGMON_SPEED=60 python3 server.py   # 실제 1초 = 1분
```

## 구조

| 파일 | 역할 |
|---|---|
| `server.py` | 앞에 떠 있는 앱·탭 감지(`lsappinfo`, AppleScript), 입력 없음 감지(`ioreg`), 경험치 계산, 알림, HTTP API (Python 표준 라이브러리만 사용) |
| `index.html` | 대시보드: 스타팅 선택, 상태, 설정, 도감, 공유 카드 |
| `pet.html` | 데스크톱 펫 화면: 스프라이트, 말풍선, 애니메이션 |
| `FigmonPet.swift` | 투명 펫 창: 걷기, 커서 따라가기, 드래그, 메뉴 막대 아이콘 |
