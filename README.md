## ✨ 어떤 앱인가요?

| | |
|---|---|
| 🐣 **같이 성장** | **1~9세대 포켓몬 550여 계열**(진화 전 모습 기준) 중에서 골라 **Lv.0**부터 키워요. 실제 게임처럼 **성장 그룹별 경험치 곡선**을 따르고, **실제 게임과 같은 레벨에 진화**해요 (예: 미뇽 → Lv.30 신뇽 → Lv.55 망나뇽). |
| ✨ **진화 연출** | 빛이 모여 하얀 실루엣이 되고, 예전 모습 ↔ 새 모습이 점점 빠르게 바뀌다가 펑! 메가진화는 키스톤 → 무지개 빛줄기 → 빛의 알이 깨지며 등장해요. |
| 🧬 **여러 갈래의 진화** | 습관으로 갈리는 **갈래 진화**, 시간대로 고르는 **이브이 8종**, **💎 메가진화 90여 종**까지 있어요. |
| 🔒 **전설·환상 도전** | 일반 포켓몬을 졸업시키면 전설·환상이 하나씩 열려요. 최종 도전은 **신의 시련**을 통과해야 하는 👑 **아르세우스**(18가지 타입 모습)예요. |
| 🗺️ **지방 배경 · 성지** | 세대마다 **관동~팔데아** 지방 배경이 다르고, 전설·환상은 **각자의 성지**(소용돌이섬, 하늘기둥, 반전세계…)에서 지내요. 시간에 따라 아침·점심·저녁·새벽 하늘도 바뀌어요. |
| 🚶 **데스크톱 펫** | 포켓몬이 화면 아래를 걸어 다니고, 일할 때는 커서 옆에서 지켜봐요. 클릭·쓰다듬기·던지기에 반응해요 (경험치는 안 줘요). |
| 🍿 **휴식 잔고 · 페널티** | 작업 5분마다 휴식 1분이 쌓여요. 잔고 없이 딴짓하면 경고 후 경험치가 깎여요. |
| 🧠 **AI 절제 모드** | (선택) ChatGPT·Claude·Gemini 등을 하루 무료 시간만큼만 쓰게 해요. |
| 🏆 **자랑 카드** | 완전 성장·메가진화하면 **인스타 스토리 크기 카드**가 떠요. 달성 기록과 뱃지가 들어가고, **최종 진화 · 메가 · 전설 · 환상 · 아르세우스**마다 디자인이 달라요. |
| 📊 **기록 · 자동 업데이트** | 앱·사이트별 작업·딴짓·AI 시간과 페널티 기록이 남아요. 새 버전은 알아서 받아 바꿔 끼워요. |

## 🚀 설치

[**Releases**](https://github.com/jinjwon/figmon/releases/latest)에서 내 컴퓨터에 맞는 파일을 받으면 돼요.

| | 🍎 macOS | 🪟 Windows |
|---|---|---|
| 지원 | **macOS 13 Ventura 이상** (Sonoma · Sequoia · Tahoe), **Apple Silicon · Intel 모두** | Windows 10 / 11 |
| 받을 파일 | `Figmon-macOS.zip` | `Figmon-Windows.zip` |
| 설치 | 압축을 풀고 `Figmon.app`을 **응용 프로그램** 폴더로 옮기기 | 압축을 풀고 `Figmon.exe`를 바탕 화면이나 내 문서 폴더에 두기 |
| 첫 실행 | 아래 [첫 실행 (macOS)](#첫-실행-macos) 참고 | "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** |
| 필요한 것 | Python 3 (없으면 앱이 개발자 도구 설치를 안내해요) | 없음 (exe 안에 다 들어 있어요) |
| 메뉴 | 메뉴 막대 아이콘 / 펫 우클릭 | 펫 우클릭 |

### 첫 실행 (macOS)
앱스토어 앱이 아니고 Apple 공증을 받지 않은 개인 프로젝트라서, 처음 한 번은 막혀요.
1. `Figmon.app`을 실행해요. 경고가 뜨면 **완료**를 눌러 닫아요.
2. **시스템 설정 › 개인정보 보호 및 보안**을 열고 맨 아래로 내려요.
3. "Figmon이(가) 차단되었습니다" 옆의 **그래도 열기**를 누르고, 암호나 Touch ID로 확인해요.
4. 다시 뜨는 창에서 **열기**를 눌러요. 다음부터는 바로 열려요.

> macOS 14 이하에서는 앱을 **우클릭 → 열기**로도 돼요. macOS 15 Sequoia부터는 이 방법이 막혀서 위의 **그래도 열기**를 써야 해요.

### 소스로 직접 실행

```bash
git clone https://github.com/jinjwon/figmon.git
cd figmon

# macOS: 앱으로 빌드해서 실행 (Xcode Command Line Tools 필요, macOS 13 이상 유니버설로 빌드돼요)
./build_app.sh && open dist/Figmon.app

# Windows: Python 3.9+만 있으면 서버 + 펫이 함께 떠요 (python.org 설치판 권장, tkinter 포함)
python server.py
```

## 🩹 설치가 안 될 때

뜨는 메시지에 따라 해결법이 달라요.

| 뜨는 메시지 | 원인 | 해결 |
|---|---|---|
| "이 버전의 macOS에서는 사용할 수 없습니다" / 아이콘에 금지 표시 | **v1.23.0 이하** 빌드 문제 (macOS 26 전용으로 빌드됐어요) | 최신 버전을 **새로 받기**. 안 열리는 앱은 자동 업데이트도 못 해요 |
| "확인되지 않은 개발자" / "악성 코드가 없음을 확인할 수 없습니다" | macOS 보안 (Gatekeeper) | [첫 실행 (macOS)](#첫-실행-macos)의 **그래도 열기** |
| "앱이 손상되었기 때문에 열 수 없습니다" | 인터넷에서 받은 파일에 붙는 격리 표시 (실제로 손상된 건 아니에요) | 앱을 응용 프로그램 폴더로 옮긴 뒤 터미널에서 아래 명령 실행 |
| 앱은 열리는데 펫이 안 나옴 / 개발자 도구 설치 창이 뜸 | Python(Xcode 명령줄 도구)이 없음 | 창에서 **설치**를 누르고, 끝나면 Figmon을 다시 실행 |
| 🪟 exe가 사라지거나 실행이 막힘 | 백신(Windows Defender 등)의 오탐 | **Windows 보안 › 바이러스 및 위협 방지 › 보호 기록**에서 허용 |
| 🍎 자동 업데이트가 안 됨 | 다운로드 폴더 등에서 바로 실행 중 | Figmon이 **"응용 프로그램 폴더로 옮길까요?"**라고 물으면 **옮기고 다시 켜기** |
| 🪟 자동 업데이트가 안 됨 | Program Files처럼 쓸 수 없는 폴더 | `Figmon.exe`를 바탕 화면이나 내 문서 폴더로 옮기기 |

"손상되었습니다"일 때 (Figmon의 격리 표시만 지워요):

```bash
xattr -dr com.apple.quarantine /Applications/Figmon.app
```

## 📖 사용법

### 1. 포켓몬 고르기
실행하면 **FIGMON 타이틀 화면**이 떠요. **▶ 시작하기**를 누르고 마음에 드는 친구를 골라 **이 친구로 할래!**를 누르면 Lv.0부터 함께 시작해요.
- **🔍 검색**: 이름(피카츄), **초성**(ㅍㅋㅊ), **도감 번호**(25). 진화형 이름으로 찾아도 진화 전 포켓몬이 나와요.
- **필터**: 세대, 타입, 진화 단계(진화 없음·2단·3단), ✨ 전설·환상
- 고르기 전에 **진화 경로**(예: "Lv.0 피카츄 → Lv.25 라이츄 (원래 진화의 돌)")와 **완전 성장까지 걸리는 시간**이 보여요.

### 2. 평소처럼 일하기
Figma나 VS Code 같은 작업 앱을 앞에 띄워 두고 일하면 돼요.
- 작업 1분 = **경험치 +3** (전설 ×0.9 · 환상 ×0.85 · 아르세우스 ×0.7)
- 작업 5분 = **휴식 잔고 +1분** (최대 60분)
- 2분 동안 키보드·마우스 입력이 없으면 자리비움으로 보고 시간에 넣지 않아요
- Figma, Sketch, Framer, VS Code, Cursor, Xcode, JetBrains, 터미널, github.com 등이 기본으로 작업 목록에 있어요. 설정에서 **🎨 디자이너 / 💻 개발자 / 둘 다** 프리셋으로 바꿀 수 있어요.

### 3. 쉬고 싶을 때
유튜브·인스타·틱톡·게임은 **휴식 잔고**를 써요. 잔고가 남아 있으면 괜찮아요. 잔고가 0이 되면:
1. 포켓몬이 커서로 달려와 부들부들 떨고, 알림과 팝업이 떠요
2. 팝업에서 **작업으로 돌아갈게**를 누르면 마지막에 쓰던 작업 앱이 바로 열려요
3. 20초 안에 돌아가지 않으면 **분당 경험치 -3** (레벨은 떨어져도 지금 진화 단계 아래로는 안 내려가요)

회의·외출 중에는 **⏸ 추적 일시정지**(30분 / 1시간 / 2시간 / 오늘 하루)로 경험치와 페널티를 멈출 수 있어요.

### 4. 데스크톱 펫

| 동작 | 결과 |
|---|---|
| 펫 클릭 | 깡총 뛰며 하트 + 한마디 (연달아 누르면 간지러워해요) |
| 펫 두 번 클릭 | 대시보드 열기 |
| 커서 올리기 | "!" 하고 알아챔 |
| 커서로 좌우로 비비기 | 쓰담쓰담 (몸을 흔들며 하트) |
| 펫 드래그 | 집어 들어 옮기기 (놓으면 떨어져서 착지) |
| 세게 던지기 | 뱅글뱅글 날아가 벽에 튕기고 착지하면 깜짝 놀람 😵 |
| 펫 우클릭 / 메뉴 막대 아이콘 | 대시보드 · 내 쪽으로 부르기 · **펫 크기(60~160%)** · 숨기기 · 추적 일시정지 · 자동 실행 · 업데이트 확인 · 종료 |

#### ⌨️ 타이핑에 맞춰 움직여요
작업 중에 키보드를 치면 펫이 말 대신 **몸짓**으로 같이 반응해요.

| 타이핑 | 펫 |
|---|---|
| 칠 때마다 | 박자에 맞춰 통통 튀며 좌우로 까딱 |
| 빠르게 몰아치기 | 타입 색으로 빛나고 양옆으로 불꽃이 튐 |
| 30초 넘게 몰입 | 발밑에서 기운이 고리처럼 퍼짐 |
| 300타마다 | 점프하며 반짝 |
| 오래 치다 멈추면 | 쭉 기지개 |
| 치는 동안 | 돌아다니지 않고 곁에 머묾 |

> 🔒 **무슨 키를 눌렀는지는 전혀 몰라요.** macOS는 시스템이 세는 "키를 누른 횟수"만, Windows는 "마우스는 그대로인데 입력이 있었는지"만 봐요. 내용은 저장하지도, 보내지도 않아요. 추가 권한도 필요 없어요.

> 쓰다듬기·던지기·클릭·타이핑 반응은 **반응만** 해요. 경험치는 오직 작업 시간으로만 오르니 꼼수는 안 통해요.

- **macOS**: 메뉴 막대 앱이에요. 화면 위에 `🎨 Lv.12`처럼 떠 있고, 대시보드 창이 열려 있을 때만 Dock에 보여요.
- **Windows**: 펫이 작업 표시줄 위를 걸어 다녀요. 대시보드는 Edge 앱 창으로 열리고, 펫을 눌러도 작업 중인 창의 포커스를 뺏지 않아요.
- **작업 앱을 켜면 등장**: 처음 실행할 때 켜 두면, 컴퓨터를 켤 때 Figmon이 조용히 실행되고, 10분 넘게 쉬다가 작업 앱을 켜면 펫이 화면 가장자리에서 걸어 나와 인사해요.

### 5. 포켓몬 바꾸기 · 졸업
- **🔄 포켓몬 바꾸기**로 언제든 바꿀 수 있지만, 새 포켓몬은 **Lv.0부터 다시** 시작해요.
- 완전 성장한 포켓몬은 **🎓 졸업**시키면 📕 도감에 남고, 전설·환상을 여는 조건이 채워져요.

### 6. 기록 보기 (📊 기록 탭)
- 기간: 오늘 / 어제 / 최근 7일 / 최근 30일 (60일까지 보관)
- 작업·딴짓·AI 시간, 잃은 경험치, 집중 비율, 요일별 막대
- **💢 페널티 받은 기록**: 언제, 어디서(예: youtube.com), 몇 분 동안, 경험치를 얼마나 잃었는지
- 기록은 내 컴퓨터(`~/.figmon/state.json`)에만 저장되고 밖으로 보내지 않아요.

### 7. 설정 (⚙︎)
- **⚡ 최근 쓴 앱·사이트 바로 분류**: 방금 쓴 앱·사이트 옆 **[작업] [딴짓] [AI] [해제]** 버튼 한 번
- **목록 편집**: 태그를 **×**로 지우고, 입력칸에 쓰고 **Enter**로 추가
- 휴식 비율, 페널티 세기, 유예 시간, 자리비움 판정 같은 값은 **정해진 범위 안에서만** 바꿀 수 있어요. 작업 1분당 경험치는 못 바꿔요 (꼼수 방지).
- **🧠 AI 절제 모드**: 하루 무료 AI 시간(기본 30분)을 넘기면 딴짓으로 쳐요
- **자동 업데이트**: 실행 10초 뒤와 1시간마다 확인해서 알아서 바꿔 끼워요. 설정에서 끄거나 바로 확인할 수 있어요.

## 🐣 성장 · 진화

### 성장 속도: 포켓몬마다 다른 경험치 곡선
실제 게임의 **성장 그룹별 경험치 곡선**(레벨의 세제곱 공식)을 그대로 써요. **낮은 레벨은 금방 오르고, 높을수록 한 레벨이 길어져요.**

| 성장 그룹 | 완전 성장(Lv.36)까지 | 예 |
|---|---|---|
| 빠름 | 약 8시간 | 삐삐, 푸린 |
| 조금 느림 | 약 9시간 (처음이 특히 빠름) | 대부분의 스타팅 |
| 보통 | 약 10시간 | 꼬렛, 이브이 |
| 변덕 (나중에 느림) | 약 10시간 (Lv.36 뒤로 아주 느려짐) | 버섯꼬, 꼴깍몬, 고래왕자 |
| 느림 | 약 12시간 | 미뇽, 가디, 셀러 |
| 변덕 (처음엔 느림) | 약 13시간 (Lv.36 뒤로 아주 빨라짐) | 토중몬, 파비코 |
| ✨ 전설 · 🌟 환상 | 약 10~15시간 | 뮤츠, 루기아, 뮤 |
| 👑 아르세우스 | 약 18시간 | 아르세우스 |

### 진화 레벨: 실제 게임 값 그대로
레벨이 아닌 조건(진화의 돌, 통신교환, 친밀도)으로 진화하는 포켓몬은 비슷한 시점의 레벨로 바꿨어요.

| 실제 게임의 진화 조건 | Figmon에서 | 예 |
|---|---|---|
| 레벨 | 그 레벨 그대로 | 파이리 → Lv.16 리자드 → Lv.36 리자몽, 미뇽 → Lv.30 신뇽 → Lv.55 망나뇽 |
| 친밀도 | 첫 진화 Lv.20, 두 번째는 앞 진화 +10 (최소 Lv.30) | 피츄 → Lv.20 피카츄, 골뱃(Lv.22) → Lv.32 크로뱃 |
| 진화의 돌 등 아이템 | 첫 진화 Lv.25, 두 번째는 앞 진화 +12 (최소 Lv.30) | 피카츄 → Lv.25 라이츄, 냄새꼬(Lv.21) → Lv.33 라플레시아 |
| 통신교환 | 첫 진화 Lv.30, 두 번째는 앞 진화 +14 (최소 Lv.30) | 롱스톤 → Lv.30 강철톤, 고우스트(Lv.25) → Lv.39 팬텀 |
| 그 밖의 특별한 조건 | 첫 진화 Lv.25, 두 번째는 앞 진화 +12 (최소 Lv.30) | 글리거 → Lv.25 글라이온, 꾸꾸리(Lv.33) → Lv.45 맘모꾸리 |

**완전 성장**은 Lv.36이에요. 마지막 진화가 더 늦은 포켓몬은 **마지막 진화 레벨**이 완전 성장이에요.

| 포켓몬 | 완전 성장 | 작업 시간 |
|---|---|---|
| 대부분의 포켓몬 | Lv.36 | 약 8~13시간 |
| 팬텀 · 자포코일 · 폴리곤Z | Lv.39~44 | 약 11~18시간 |
| 메타그로스 · 킹드라 | Lv.45~46 | 약 21~24시간 |
| 한카리아스 · 보만다 · 미끄래곤 | Lv.48~50 | 약 30~33시간 |
| 망나뇽 · 마기라스 · 거대코뿌리 | Lv.55~56 | 약 45~47시간 |
| 드래펄트 · 삼삼드래 | Lv.60~64 | 약 58~70시간 |

진화하지 않는 포켓몬(잠만보, 뮤 등)은 모습은 그대로지만 레벨이 오를수록 몸집이 커져요.

### 특별한 진화

| 종류 | 대상 | 무엇이 정하나 |
|---|---|---|
| 🔮 갈래 진화 | 랄토스, 배루키, 코스모그 등 13계열 | 키우는 동안의 습관 (자동) |
| 🌗 이브이 진화 | 이브이 (8가지) | 일한 시간대 → 직접 고르기 |
| 💎 메가진화 | 리자몽, 뮤츠, 루카리오 등 90여 종 | Lv.45 도달 (X·Y는 습관) |
| 👑 아르세우스 타입 | 아르세우스 (18가지) | 함께 일한 시간 → 직접 고르기 |

**🔮 갈래 진화**: 진화 레벨이 되면 **습관 점수가 가장 높은 쪽**으로 진화해요. 대시보드의 "🔮 진화 예측"에서 어느 쪽으로 기우는지 볼 수 있어요.

| 조건 | 점수 | 예 |
|---|---|---|
| ☀️ 낮 / 🌙 밤 | 낮(6~18시)과 밤 중 언제 더 많이 일했나 | 솔가레오/루나아라, 포푸니크/포푸니라, 뷰티플라이/독케일 |
| 🔥 열심히 | 하루 평균 작업 시간 (4시간이면 만점) | 엘레이드, 시라소몬, 헌테일, 애프룡 |
| 🎯 딴짓 줄이기 | 딴짓 비율이 낮을수록 | 가디안, 홍수몬, 분홍장이, 과미드라 |
| 🍿 균형 | 휴식 잔고는 잘 쓰고 페널티는 적게 | 카포에라, 단지래플 |

**🌗 이브이 진화**: 이브이로 일한 시간이 시간대별로 쌓이고, **Lv.20**에 **25% 넘게 일한 시간대**의 진화형 중에서 직접 골라요.

| 시간대 | 진화 후보 |
|---|---|
| 🌅 아침 (6~11시) | 리피아 · 님피아 |
| ☀️ 점심 (11~17시) | 에브이 · 쥬피썬더 |
| 🌇 저녁 (17~21시) | 부스터 · 샤미드 |
| 🌙 새벽 (21~6시) | 블래키 · 글레이시아 |

**💎 메가진화**: 메가진화가 있는 포켓몬은 마지막 모습에서 **Lv.45**에 메가진화해요 (완전 성장이 더 늦은 포켓몬은 완전 성장할 때).
- 리자몽·뮤츠·라이츄처럼 **X·Y**가 있으면 습관으로 정해져요: 오래 일하면(🔥) **X**, 딴짓을 줄이면(🎯) **Y**
- 메가진화한 뒤에는 **원래 모습 ↔ 메가 모습**을 바꿀 수 있어요. 페널티로 Lv.45 아래로 떨어지면 원래 모습으로 돌아가요.

### ✨ 진화 연출
- **일반 진화**: 빛이 모여들어 하얀 실루엣이 되고, 예전 모습 ↔ 새 모습이 점점 빠르게 바뀌다가 펑! 하고 새 모습이 나타나요.
- **💎 메가진화**: 키스톤이 빛나고 무지개 빛줄기가 뻗어 나가요. 무지개 빛의 알이 포켓몬을 감쌌다가 깨지며 메가 모습이 나타나요.
- 대시보드와 데스크톱 펫(macOS·Windows) 모두 나와요. 동작 줄이기를 켜면 연출 없이 바로 바뀌어요.

### 🔒 전설 · 환상 포켓몬
처음엔 잠겨 있어요. 일반 포켓몬을 **완전 성장까지 키워 졸업**시키면 하나씩 열려요.

| 난이도 | 대상 | 여는 조건 |
|---|---|---|
| ✨ 전설 | 프리져, 루기아, 레쿠쟈 등 | 같은 세대 1~3마리 졸업 (능력치가 셀수록 많이) + 같은 타입 1마리 |
| 🌟 환상 | 뮤, 세레비, 다크라이 등 | 전설 조건보다 1마리 더 |
| 👑 아르세우스 | 아르세우스 하나 | **신의 시련** 4가지 모두 |

| 예 | 여는 조건 |
|---|---|
| 프리져 | 1세대 1마리 졸업 (그중 얼음 1마리) |
| 뮤츠 | 1세대 3마리 졸업 (그중 에스퍼 1마리) |
| 루기아 | 2세대 3마리 졸업 (그중 에스퍼 1마리) |
| 레쿠쟈 | 3세대 3마리 졸업 (그중 드래곤 1마리) |
| 디아루가 | 4세대 3마리 졸업 (그중 강철 1마리) |

선택 창의 잠긴 카드에 "🔒 1세대 2/3 · 에스퍼 1/1"처럼 진행도가 보여요. 열면 전설·환상마다 다른 **성지 배경**에서 지내요.

**👑 아르세우스: 신의 시련** — 아래 네 가지를 **모두** 채워야 열려요.

| 시련 | 필요 |
|---|---|
| 졸업한 포켓몬 | 12마리 |
| 졸업시킨 타입 종류 | 10가지 |
| 4세대 포켓몬 졸업 | 4마리 |
| 창조의 신(디아루가·펄기아·기라티나) 졸업 | 1마리 |

열고 나서도 함께 **3시간** 일할 때마다 새 타입(플레이트)의 힘을 얻어 **18가지 모습**이 하나씩 열려요 (모두 열기까지 51시간).
