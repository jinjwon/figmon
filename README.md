## ✨ 어떤 앱인가요?

| | |
|---|---|
| 🐣 **같이 성장** | 1~9세대 스타팅 27마리 중 하나를 골라요. **진화 전 모습, Lv.0**부터 시작해서 Lv.16에 1차 진화, Lv.36에 최종 진화해요. |
| 🚶 **데스크톱 펫** | 포켓몬이 화면 아래를 돌아다니고, 일할 때는 커서 옆에 와서 지켜봐요. 레벨이 오를수록 몸집도 커져요. |

| 💢 **페널티** | 잔고 없이 딴짓하면 경고 후 경험치가 깎여요. 레벨은 떨어져도 퇴화는 안 해요. |
| 🧠 **AI 절제 모드** | (선택) ChatGPT·Claude·Gemini 등을 하루 무료 시간만큼만 쓰게 해요. |

## 🚀 설치

**필요한 것:** macOS, Python 3(macOS 기본 내장), Xcode Command Line Tools

```bash
# 1) Command Line Tools (처음 한 번만, 이미 있으면 생략)
xcode-select --install

# 2) 내려받기
git clone https://github.com/jinjwon/figmon.git
cd figmon

# 3) 실행
./start.command
```

> Finder에서 `start.command`를 **더블클릭**해도 돼요. 처음 실행할 때 데스크톱 펫 앱을 자동으로 빌드해요(10초 정도).
> "확인되지 않은 개발자" 경고가 뜨면 파일을 **우클릭 → 열기**로 실행해 주세요.

## 📖 사용법

### 1. 타이틀 화면 → 포켓몬 고르기
실행하면 **FIGMON 타이틀 화면**이 떠요.
**▶ 시작하기**를 누르면 포켓몬 선택 창이 열려요. 세대 탭(1~9세대)에서 마음에 드는 친구를 골라 **이 친구로 할래!**를 누르면 Lv.0부터 함께 시작해요.

### 2. 평소처럼 일하기
Figma나 VS Code 같은 작업 앱을 앞에 띄워 두고 일하면 돼요.
- 작업 1분 = **경험치 +1** (50 경험치마다 레벨 업)
- 작업 5분 = **휴식 잔고 +1분**
- 2분 동안 키보드·마우스 입력이 없으면 자리비움으로 보고 시간에 넣지 않아요

| 레벨 | 모습 | 필요한 작업 시간 (대략) |
|---|---|---|
| Lv.0 | 기본형 (예: 파이리) | 시작 |
| Lv.16 | 1차 진화 (예: 리자드) | 약 13시간 |
| Lv.36 | 최종 진화 (예: 리자몽) | 약 30시간 |

### 3. 쉬고 싶을 때
유튜브·인스타·틱톡·게임은 **휴식 잔고**를 써요. 잔고가 남아 있으면 페널티가 없어요.
잔고가 0이 되면:
1. 포켓몬이 커서로 달려와 부들부들 떨고, macOS 알림과 팝업이 떠요
2. 팝업에서 **작업으로 돌아갈게**를 누르면 마지막에 쓰던 작업 앱이 바로 열려요
3. 20초 안에 돌아가지 않으면 **분당 경험치 -3**

### 4. 데스크톱 펫 다루기
| 동작 | 결과 |
|---|---|
| 클릭 | 대시보드 열기 |
| 드래그 | 집어 들어 옮기기 (놓으면 떨어져서 착지) |
| 우클릭 / 메뉴 막대 `🎨 Lv.12` | 대시보드 · 내 쪽으로 부르기 · 숨기기 · 종료 |

### 5. 포켓몬 바꾸기
대시보드의 **🔄 포켓몬 바꾸기**나 타이틀 화면에서 언제든 바꿀 수 있어요.
⚠️ 바꾸면 지금 포켓몬과 헤어지고, 새 포켓몬은 **Lv.0부터 다시** 시작해요.
최종 진화한 포켓몬은 **🎓 졸업**시키면 도감에 남겨 둘 수 있어요.

### 6. 설정 (⚙︎)
- **🎨 디자이너 / 💻 개발자 / 둘 다** 프리셋으로 작업 앱 목록을 한 번에 바꿀 수 있어요
- 작업·딴짓·AI 앱과 사이트 목록을 직접 고칠 수 있어요
- 경험치, 휴식 비율, 페널티 세기, 유예 시간 같은 수치를 조절할 수 있어요
- **🧠 AI 절제 모드**: 켜면 하루 무료 AI 시간(기본 30분)을 넘긴 순간부터 딴짓으로 쳐요

### 처음 실행할 때 권한
macOS가 *"Chrome(또는 Safari)을 제어하려고 합니다"*라고 물으면 **허용**을 눌러 주세요.
지금 보고 있는 탭이 유튜브인지 github인지 구분할 때만 써요. 데이터는 내 Mac(`~/.figmon/state.json`)에만 저장되고, 밖으로 보내지 않아요.

### 빨리 감기 (테스트용)
```bash
FIGMON_SPEED=60 python3 server.py   # 실제 1초 = 1분
```

## 🗂 구조

| 파일 | 역할 |
|---|---|
| `server.py` | 앞에 떠 있는 앱·탭 감지, 입력 없음 감지, 경험치 계산, 알림, HTTP API (Python 표준 라이브러리만 사용) |
| `index.html` | 대시보드: 타이틀 화면, 포켓몬 선택, 상태, 설정, 도감, 공유 카드 |
| `pet.html` | 데스크톱 펫 화면: 스프라이트, 말풍선, 애니메이션 |
| `FigmonPet.swift` | 투명 펫 창: 걷기, 커서 지켜보기, 드래그, 메뉴 막대 |
